🥑 NutriChef - Your Smart Kitchen Assistant
NutriChef is a full-stack MERN application designed to revolutionize your home cooking experience. It acts as a smart kitchen assistant that helps you manage your pantry, reduce food waste, and discover delicious meals tailored to you, all powered by AI.

✨ Core Features
Smart Pantry Management: Effortlessly track your kitchen inventory, monitor expiration dates, and get alerts before food spoils.

AI-Powered Recipe Generation: Unleash your inner chef with an AI that crafts unique recipes from the ingredients you already own.

Personalized Meal Planning: Get a full 7-day meal plan generated by AI, tailored to your specific dietary needs and health goals (Pro feature).

Pro Subscriptions: A secure payment system using Razorpay allows users to unlock premium AI-powered features.

Role-Based Authentication: A secure system with JWT authenticates users and manages permissions for free users, pro members, and administrators.

Full-Featured Admin Panel: A comprehensive dashboard for administrators to view site statistics, manage all users, and moderate user-submitted content.

PDF Export: Pro users can export their weekly meal plans as a clean, formatted PDF.

🛠️ Technology Stack
Frontend
React.js: A powerful library for building modern user interfaces.

React Router: For seamless client-side navigation.

Tailwind CSS: For a utility-first, modern styling workflow.

React Context: For robust global state management (Authentication & App Data).

Axios: For making promises-based HTTP requests to the backend.

Vite: For a lightning-fast frontend development experience.

Backend
Node.js & Express.js: For building a fast, scalable, and secure RESTful API.

MongoDB: A flexible NoSQL database for storing application data.

Mongoose: An elegant ODM for data modeling and validation.

JSON Web Tokens (JWT): For stateless and secure user authentication.

Nodemailer: For sending automated emails (welcome, password reset, receipts).

PDFKit: For generating PDF documents on the server.

OpenRouter API: To leverage powerful AI language models for content generation.

Razorpay API: For secure payment processing.
